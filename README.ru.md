# Chiaki-ng PS3 (с поддержкой игры через интернет)

**🇷🇺 Русский** | [🇬🇧 English](README.md)

![Chiaki-ng PS3](ps3/pkgfiles/ICON0.PNG)

**PS4 и PS5 Remote Play на PlayStation 3 — как в локальной сети, так и через интернет (PSN).**  
Играй на своей PS3 (с геймпадом DualShock 3) в удалённую PS5 или PS4, **ничего не настраивая на стороне PS5** (не нужны проброс портов на роутере, белый IP или ввод PIN-кода с экрана PS5).

## Возможности

- **Игра через интернет через PSN (NAT UDP Hole Punching)** — PS3 сама обновляет OAuth2-токен PSN, будит удалённую PS5 из режима покоя и пробивает NAT с обеих сторон.
- **720p @ 60 FPS** на аппаратном H.264-декодере PS3 (`libvdec` на SPU).
- Поиск консолей PS5 в аккаунте PSN прямо с PS3 (**START → Find PS5 consoles via PSN**) и поиск консолей в локальной сети (LAN).
- Стереозвук с автоматической коррекцией рассинхрона.
- Полная поддержка **DualShock 3** (аналоговые курки L2/R2 и вибрация).
- Настройки плавности кадров (frame pacing): минимальная задержка, сбалансированный или максимально плавный режим.

## Требования

- Прошитая PS3 с поддержкой установки `.pkg` (CFW, тестировалось на Rebug + Cobra).
- PS5 или PS4 (в локальной сети или удалённо через интернет), на которой выполнен вход в PSN и включён Remote Play (**Настройки → Система → Дистанционная игра → Включить дистанционную игру**).
- Для стабильной картинки рекомендуется подключить PS3 к интернету **по кабелю (Ethernet)**.

*Не поддерживается:* 1080p / HEVC на PS5 (аппаратный декодер PS3 поддерживает только H.264 до 720p), микрофон, жесты сенсорной панели и гироскоп.

## Установка

1. Скачай **`chiaki-ps3.pkg`** со страницы [последнего релиза](../../releases/latest).
2. Скопируй `chiaki-ps3.pkg` в корень USB-флешки (FAT32), вставь в PS3 и установи через **Package Manager → Install Package Files**.
3. Приложение **Chiaki-ng PS3** появится в меню **Игра (Game)**.

## Настройка

### Вариант 1: Игра через интернет (удалённая PS5 — без настроек на стороне PS5)

1. На компьютере (Mac / Linux / Windows) запусти скрипт (нужен только Python 3, без установки доп. пакетов):
   ```bash
   python3 ps3/tools/psn_login.py chiaki.cfg
   ```
   Откроется официальная страница входа Sony PSN. Войди в свой аккаунт, а когда браузер покажет пустую страницу `redirect` — скопируй полный URL из адресной строки и вставь в терминал.  
   Скрипт сам получит твой `psn_account_id`, `psn_refresh_token` и `duid` удалённой PS5 и сохранит готовый `chiaki.cfg`.  
   *(Если ты уже пользуешься `chiaki-ng` на ПК/Mac, можно вместо этого экспортировать его `.ini` и выполнить `python3 ps3/tools/export_keys.py exported.ini > chiaki.cfg`.)*
2. Скопируй `chiaki.cfg` в корень USB-флешки (FAT32) и вставь её в PS3.
3. Запусти **Chiaki-ng PS3** — при первом запуске настройки подхватятся автоматически (либо импортируй вручную через **START → Import chiaki.cfg from USB**). После импорта удали `chiaki.cfg` с флешки, чтобы не хранить токены на съёмном носителе.
4. Выбери свою PS5 (статус `PSN (Internet)`) и нажми **✕**. PS3 сама разбудит PS5 через PSN, пробьёт NAT и запустит стрим.

> **Совет при строгом NAT:** если пробитие NAT не проходит с первого раза (например, мобильный интернет или двойной NAT провайдера), включи **START → NAT port guessing (PSN): On** и попробуй снова.

### Вариант 2: Локальная сеть (LAN)

1. Включи PS4/PS5 в той же домашней сети — она автоматически появится в списке.
2. Нажми **✕**, введи свой PSN Account ID (если ещё не указан) и 8-значный PIN с экрана консоли (**PS5: Настройки → Система → Дистанционная игра → Связать устройство**).
3. Чтобы консоль пробуждалась из режима покоя, включи в настройках энергосбережения «Сохранять подключение к Интернету» и «Разрешить включение PS5 из сети».

## Управление (DualShock 3 → PS5 / PS4)

| DualShock 3 | PS5 / PS4 |
|---|---|
| Кнопки, крестовина, стики, L1/R1, L3/R3 | те же |
| L2 / R2 | L2 / R2 (аналоговые) |
| START | OPTIONS |
| SELECT (нажать) | SHARE / Create |
| SELECT + START | кнопка PS |
| SELECT + ✕ | нажатие на сенсорную панель (вместо ✕: L1 / R1 — левая / правая половина) |
| SELECT + △ | показать / скрыть оверлей статистики (FPS, задержка, битрейт) |
| **SELECT + ○ (удерживать 1 сек)** | **завершить стрим** |

В главном меню: **✕** — подключиться, **△** — опции консоли (включая выбор режима Auto / PSN), **□** — добавить по IP, **START** — настройки, **○** — выход.

## Советы и логи

- Включи на телевизоре **Игровой режим (Game Mode)** — обработка картинки телевизором часто добавляет больше задержки, чем сам стрим.
- Если что-то пошло не так, подробный лог сохраняется в `/dev_hdd0/game/CHIAKIPS3/USRDIR/chiaki.log` (предыдущий запуск — `chiaki.prev.log`).
